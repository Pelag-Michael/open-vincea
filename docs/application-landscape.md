# Application landscape

Vincea's private implementation contains application-integration work across several creative software families.

This page describes the **landscape**, not a support guarantee.

## 3D, DCC, and game production

Integration work exists for applications including:

- Blender
- Maya
- Houdini
- 3ds Max
- Cinema 4D
- Unreal Engine
- Marmoset Toolbag
- Character Creator

## Design and Adobe workflows

Integration work exists for applications including:

- Photoshop
- Illustrator
- After Effects
- Premiere Pro
- InDesign
- Animate
- Audition
- Lightroom

## CAD and design engineering

Integration work exists for applications including:

- AutoCAD
- Fusion 360
- SketchUp

## Texturing and material workflows

Integration work exists for Substance-family applications.

## Video

Integration work also exists around DaVinci Resolve workflows.

## Protocol-based creative applications

Some creative applications are better integrated through an application-supported protocol rather than a conventional in-app addon. Vincea treats that as a separate integration shape while keeping the user-facing capability model consistent.

## Maturity warning

Integration depth varies significantly. Some applications have richer inspection, action, verification, and test coverage than others.

The public repository intentionally avoids presenting a raw internal inventory as a compatibility promise.
